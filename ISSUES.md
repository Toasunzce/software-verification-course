# Дефекты

| ID | Название | Требование | Приоритет |
|---|---|---|---|
| ISSUE-1 | Пустой файл принимается при загрузке | FR-4 | Средний |
| ISSUE-2 | Поиск по несуществующему документу возвращает 200 | FR-14 | Низкий |

## ISSUE-1.
- **Шаги:** `POST /documents`, загрузить `empty.txt` размером 0 байт.
- **Ожидается:** 422 с описанием ошибки.
- **Фактически:** 201, документ создан; `/index` переводит его в `failed` ("В документе не найден текст").

## ISSUE-2.
- **Шаги:** `POST /search` с `{"query": "text", "document_id": 999}`; аналогично `POST /ask`.
- **Ожидается:** 404.
- **Фактически:** 200 с пустым списком (для `/ask` со стандартной фразой об отсутствии информации).
